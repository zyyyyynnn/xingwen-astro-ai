本文记录对本地 MAVIS 参考快照的可复核事实，不定义当前项目的技术栈、Contract、模块责任或实现方案。快照没有足够证据证明 MAVIS 的展开全称或团队归属，本文不作相关推断。

## 许可与再分发

- MAVIS 只能作为研究比较材料，不能作为生产实现、权威规范或已验证科研能力。
- 本仓库不分发原始 MAVIS 资产。任何重新引入必须先取得可验证的许可证或书面授权，并通过独立安全与来源审查。
- 原始快照含硬编码凭据、导入期全局状态、远程执行和模型生成 Python 执行面；本文不记录任何凭据值。

## 已核验结构事实

核验对象为本地 MAVIS 参考快照的 `data/task_benchmark`。“相对完整”仅表示目录中除任务 JSON 外还保留了输入、代码、说明或图像等任务材料，不表示任务可复现、实现正确或资产可再分发。

| 项目                       | 数量 | 判定口径                                                            |
| -------------------------- | ---: | ------------------------------------------------------------------- |
| benchmark 任务目录         |  160 | `task_benchmark` 的直接子目录                                       |
| 相对完整任务               |   99 | 排除以下 59 个仅转换结果目录和 2 个有限双 JSON 目录                 |
| 仅转换结果                 |   59 | 目录中只有 `divide_task_converted.json`                             |
| 有限双 JSON                |    2 | 目录中只有两个任务 JSON，没有其他任务资产                           |
| 含 `code/visual.py` 的目录 |   89 | 文件存在性统计；不能表述为“89 个带图片任务”                         |
| API JSON 参考文件          |   11 | `data/api_for_prompt` 中的 API 工具文档                             |
| 实际进入原 Prompt 路径     |    4 | `wwt_agent.json`、`getData.json`、`skyfield.json`、`photutils.json` |

11 个 JSON 的存在不等于都被运行时使用。原 `prompt10.py` 只直接读取上述 4 个文件，其余 7 个没有进入该 Prompt 的直接加载路径。

## Agent 与运行路径

- `mutil_agent10.py` 是历史 Django Web 路径实际接线的版本；`web_django/mydjango/user/views.py` 导入并调用它。
- `mutil_agent12.py` 由 `run_all.py` 用于批量规划/评测实验，不是 Web 产品接线。
- 未发现 `mutil_agent11.py` 的外部入口；agent11/12 均保留不可达的历史执行段，不能据此声称相应能力可用。
- agent12 的历史路径中存在一次未消费生成器的调用；调用没有被迭代，会形成静默 no-op，不能作为成功执行证据。
- 原 `prompt10.py`、11 个工具文档和实际运行路径并不一致：Prompt 使用本机绝对路径并只加载 4 个 JSON，且源文件末尾混入了非 Python 临时文本。

这些事实只描述被审计快照，不保证其他版本具有相同结构。

## 可研究但未采纳的方向

相关论文将动态工具检索、前置任务递归推导和 WWT 交互作为研究主题。这些内容可用于比较工具契约、直接依赖表达和结构化结果到可视呈现的边界，但论文自述不等于本项目已验证或采纳其方法。

[WWT 官方文档](https://docs.worldwidetelescope.org/research-app/latest/controlling/)说明其 Research App 可嵌入 Web 应用并通过受约束的 JSON 消息控制；这只证明技术上存在 Web 嵌入方式。项目不引入 WWT，也不采用 MAVIS 的共享 WWT 协议。

## 当前项目边界

当前项目不采用 MAVIS 的以下做法：

- 模型生成 Python 的直接执行或任意代码执行；
- 远程 Jupyter 执行路径；
- 导入期 Redis、网络连接或任务启动；
- 跨请求共享的模块级可变状态；
- 未经当前 Pydantic Contract、Evidence 规则和安全评审采纳的工具协议；
- 任何未证明再分发权限的 JSON、图片、数据集或原始压缩包。

若后续 Issue 希望借鉴某项设计，必须重新核验来源与许可证，并通过当前 API、Data Model、Workflow、Reasoning 和安全规范冻结；不得直接复制此参考快照。
