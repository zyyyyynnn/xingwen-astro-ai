# Roadmap

## M0：仓库基础

- 创建 GitHub 仓库。
- 初始化文档。
- 确认开发岗位和 Git 工作流。
- 建立 Issue / PR 模板。

## M1：项目骨架与接口跑通

- Vue 前端项目骨架。
- FastAPI 后端项目骨架。
- Qwen 调用层。
- PostgreSQL 连接。
- 创建任务 / 查询任务接口。
- Mock 任务流程。

## M2：自动化数据分析主链路

- 接入系外行星主数据源。
- 字段清洗和单位统一。
- CSV 导出。
- 数据字典。
- 溯源报告。
- 数据质量评分初版。

## M3：智能文献总结

- 文献输入格式。
- Qwen 文献总结 Prompt。
- 结构化文献 JSON。
- 文献总结页面。
- 文献结果质量检查规则。

## M4：学术图谱可视化

- 图谱节点和边结构。
- 图谱接口。
- 图谱前端页面。
- 节点详情面板。
- 证据溯源入口。

## M5：反馈修正与公网 Demo

- 用户反馈入口。
- 字段 / 单位 / 来源问题局部修正。
- 缓存兜底数据。
- 公网 Demo。
- 材料组截图和录屏素材。
