# Project Charter

## 项目名称

星文智析 AI 科研工具

## 项目定位

面向天文科研场景的一体化 AI 科研工具，围绕自动化数据分析、智能文献总结、天文学术图谱可视化三大核心功能，完成从科研问题到可用数据与证据图谱的闭环。

## MVP 主案例

系外行星候选体与宿主恒星参数整合。

## 成功标准

- 有稳定公网 Demo。
- 能跑通主案例完整流程。
- 输出结果可下载、可溯源、可复现。
- 三大功能形成一条科研工作流。
- 材料组可获得真实截图、结果和技术说明。

## 非目标

- 不承诺任意科研问题全自动处理。
- 不承诺任意论文或任意图表全自动解析。
- 不做泛聊天助手。
- 不做无主线的功能堆叠。

## 决策原则

1. 先保证主链路稳定。
2. 新功能必须增强主案例。
3. 展示效果服务真实能力。
4. 文档口径不得超过系统实现。
