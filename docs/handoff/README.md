# Handoff Guide

本目录用于开发组向总负责人/材料组交接真实技术素材。开发组不负责 Word、PPT、视频成片制作，但必须提供可引用、可复现、不过度宣传的技术材料。

## 1. 交接内容

| 类型 | 内容 | 文件建议 |
| --- | --- | --- |
| 页面截图 | 首页、任务流程、数据结果、文献总结、学术图谱、反馈修正 | `screenshots/*.png` |
| 导出结果 | CSV、数据字典、溯源报告 | `exports/*` |
| 图谱样例 | Graph JSON、节点详情、证据详情 | `graph/*` |
| 接口说明 | 核心 API 请求和响应 | `api-examples/*.json` |
| 演示说明 | 固定输入、演示步骤、失败兜底说明 | `demo-script.md` |
| 技术说明 | 架构图、模块说明、数据来源说明 | `technical-notes.md` |

## 2. 素材要求

- 必须来自真实系统运行或明确标注的真实运行缓存。
- 截图中不能出现 API Key、数据库密码、内部 Token。
- 未实现能力只能写为“规划/预留/后续扩展”。
- 数据来源必须可追踪到 URL、查询参数或文献记录。
- 演示步骤必须可复现。

## 3. 推荐交接节奏

| 阶段 | 交接物 |
| --- | --- |
| M1 | Mock 工作流截图、API 初版说明 |
| M2 | 数据结果截图、CSV、字段字典、溯源报告 |
| M3 | 文献总结截图、PaperSummary JSON |
| M4 | 图谱截图、Graph JSON、证据详情 |
| M5 | 公网 Demo URL、完整演示脚本、最终截图包 |

## 4. 禁止事项

- 不交付手写假数据冒充系统输出。
- 不把模型推断写成已验证科研结论。
- 不在截图、文档、视频素材中暴露密钥。
- 不承诺任意科研问题、任意 PDF、任意图表全自动处理。
