# Acceptance Criteria

## MVP 总验收标准

- 公网 Demo 可访问。
- 主案例完整跑通。
- 至少 2 类真实来源数据进入结果。
- CSV、数据字典、溯源报告可导出。
- 文献总结有结构化 JSON。
- 图谱节点可点击并显示证据。
- 用户反馈能触发局部修正。
- 关键模型调用和外部 API 有缓存兜底。

## A 前端验收标准

- 能输入科研目标。
- 能展示任务进度。
- 能展示数据表、字段说明、来源和质量评分。
- 能展示文献总结。
- 能展示学术图谱。
- 能提交用户反馈。
- 页面适合比赛展示和录屏。

## B 后端验收标准

- FastAPI 服务可启动。
- Qwen 调用封装可用。
- 任务状态可流转。
- API 返回统一 JSON。
- Postgres 可保存任务、结果、来源和反馈。
- API Key 不暴露到前端。
- 有缓存兜底。

## C 数据验收标准

- 能获取主案例相关数据。
- 能完成字段对齐和单位统一。
- 能生成 CSV。
- 能生成数据字典。
- 能生成来源记录。
- 能输出数据质量评分。

## D 文献与图谱验收标准

- 能输出结构化文献总结。
- 能生成 Paper / Dataset / Field / Evidence 节点。
- 能生成图谱边。
- 图谱节点能追溯到证据。
- 文献总结不得编造来源或结论。
