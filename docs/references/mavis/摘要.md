# MAVIS 非规范参考摘要

本文记录对本地 MAVIS 参考快照的能力与安全审计，不定义当前生产 Contract。用户已确认该源码来自合理渠道；是否采用仍由质量、安全、依赖与当前模块边界决定。

## 已核验能力

实际 Web 路径由 Django `user/views.py` 调用 `mutil_agent10.py`，通过模型把任务分发给 WWT、数据获取、Skyfield 行星计算和 Photutils 图像处理路径；Vue `WWTComponent.vue` 使用 `@wwtelescope/engine-helpers`。四份实际 Prompt 工具目录位于 `data/api_for_prompt/{wwt_agent,getData,skyfield,photutils}.json`。

能力覆盖 Simbad 对象/区域查询、SkyView FITS、太阳系位置与升落中天事件、FITS 背景/检测/测光参考流程，以及 WWT 定位、时间、FITS 图层、圆/线标注和太阳系背景。`data/task_benchmark` 提供大量脚本级示例，但目录存在不等于能力可复现或已验证。

## 当前采用

- Simbad 与 SkyView 通过官方 Astroquery Adapter；
- FITS 解码和坐标/图像基础通过 Astropy；背景统计、质心、源检测、分割和孔径测光通过 Photutils；
- 星历与升落中天、晨昏、月相、季节、月食、合/冲事件通过 Skyfield，并使用 `skyfield-data` 随包提供的 DE421，避免运行时隐式下载；
- WWT 使用官方 engine、engine-helpers 与 engine-types 包，形成声明式 scene；支持中心/FOV、固定观测时间、背景、坐标网格、Project-owned FITS 图层、圆/线/标签标注；
- WWT WebGL engine 由 Workspace 级单例生命周期管理，React StrictMode、场景切换、卸载、Blob URL 和图层清理均由同一 session boundary 处理；
- UI 沿用当前 React Workspace、Domain/Repository Query 与 `@xingwen/design-tokens`，不复制 Vue/Django 第二套应用壳。

## 未采用的危险边界

- 模型生成 Python、远程 Jupyter kernel 和任意 notebook/code 执行；
- 硬编码 API key、Jupyter token、Django secret、本机 IP 与绝对路径；
- 导入期 Redis/网络状态、跨请求模块级可变数组和递归补任务循环；
- 通过 WebSocket 传自由命令控制 WWT；
- 将 XLSX/FITS 文件介绍文本当作科学 Evidence；
- 复制参考快照内的 WWT vendor bundle、模型客户端或历史 Agent 版本。

当前模型 Function Calling、实际 worker、Gaia/IVOA 数据源以及全种类 Artifact Renderer 基础分别保留给仓库中已有的唯一能力边界，避免在科学模块重复实现。详细落点见 [Reference Integration Traceability](../INTEGRATION_TRACEABILITY.md)。
