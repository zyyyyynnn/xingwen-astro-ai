# AutoAstro 非规范参考摘要

| 元数据 | 值 |
| --- | --- |
| Authoring source | 本地参考快照 `AutoAstro/AutoAstro` |

本文记录参考源码的能力形状与当前采用裁决，不定义生产接口。

## 已核验能力

AutoAstro 包含自然语言计划、任务依赖表达、数据载入与分析、目录交叉匹配、统计/绘图、表格分类与回归、时间序列、图像分类、生成代码执行、失败纠正和客户端轮询。主要证据位于 `code/plan_generate.py`、`code/framework_executor.py`、`code/load_and_analyze_data.py`、`code/cross_match.py` 与 `model/self_model/*`。

参考实现把计划、生成代码、文件系统、副进程、模型训练与修复循环耦合在同一执行器中，并依赖固定本机路径和自由文本协议。其分析任务覆盖面有价值，但该执行边界不能进入当前生产链。

## 当前采用

- 自然语言任务先冻结为 `ResearchContract.scientific_tasks`，再由 deterministic RunPlan 投影到 canonical steps。
- 交叉匹配入口直接调用仓库既有 `services.data_pipeline.crossmatch.align_cross_source_records`，不复制参考算法。
- 数据画像、描述统计、受控假设检验、相关分析和声明式图表进入 fail-closed `ScientificSkillRegistry`。
- KMeans/DBSCAN、PCA、silhouette 与 IsolationForest/稳健 Z 分数承接聚类、降维和异常检测，不执行模型生成代码。
- 表格分类/回归、等长时间序列分类、时间序列预测和图像分类采用受资源约束的 scikit-learn 实现，记录 split、baseline、交叉验证、分类校准、特征重要性、算法版本与 input/output hash；不搬运参考仓库的大量模型配置和训练脚本。
- 上传 CSV/JSON 已可经 `ResearchInput` 内容存储解析成有界行输入；结果形成 AnalysisReport、Visualization、ModelEvaluation 或 ModelArtifact，并通过 Publisher/Evidence/SourceSnapshot 边界发布。

## 明确替换

- 模型生成 Python、`subprocess` 执行与代码纠错循环由注册技能和参数白名单替换；
- 文件路径传值由 Project-owned ArtifactVersion、ResearchInput、SourceSnapshot 与内容寻址存储替换；
- 模块级任务记忆由 immutable Contract、Run、Attempt、Event 和 ArtifactVersion 替换；
- 自建深度学习脚本由当前任务规模下更易复现、可测试且维护成本更低的官方 scikit-learn estimator 替换；参考实现的导入即训练、硬编码数据/权重路径、以测试集早停和仅统计末批次等错误不保留。

实际 worker 调度由 `ResearchRunWorker` 与 Persistent Workflow Executor 承担；科学模块只提供 task-owned Adapter/Publisher，不建立第二套执行器。详细映射见 [Reference Integration Traceability](../INTEGRATION_TRACEABILITY.md)。
