本文是 [参考资料](../README.md) 目录下的可复核实现摘要，不替代当前 Prompt、Schema、Evidence 或 Workflow Authority。

## 已核验能力

参考源码是一条单文件两阶段论文总结流水线：清理 Markdown，按标题切段，通过模型把章节归入 Research Background、Methodology、Experiments、Dataset、Discussion、Limitations、Research Questions 七类，再分别总结并合并为 Markdown/JSON。核心证据位于 `get_splite_answer`、`splite_paper_by_content`、七个 `extract_*` 函数和 `step2_generate_single`。

可复用的核心不是文件编排或硬编码路径，而是七段认知覆盖模型以及“先章节归类、再按段提取”的处理顺序。

## 当前采用

- `PaperSummaryArtifactContent` 已直接替换为 background、methodology、dataset、experiments、discussion、limitations、research_questions 七段 canonical Schema；没有旧五段字段、别名或双写层。
- `services/paper_pipeline/summary.py` 与当前 Prompt Registry 实现七段结构化输出；候选必须经过现有论文来源、Evidence、hash 与 Publisher 边界。
- 当前 Fixture、Benchmark、Pydantic/JSON Schema、TypeScript DTO 和前端 Domain 均使用同一七段模型。
- 参考源码中的文本拼接 Prompt 没有复制；其目标格式已转写为当前受版本控制、可哈希的 Prompt 与 typed result。

## 未采用的实现

- 本机绝对路径、临时目录与自由文件写入；
- 原始模型客户端和把完整 prompt/response 写日志的做法；
- 以空字符串或 `None` Markdown 伪装成功；
- 仅靠一级标题正则生成不带 Evidence 的 JSON；
- 将整篇无标题论文同时复制到七个分类的降级路径。
