# Project Charter

## 项目名称

星文智析 AI 科研工具

## 项目定位

面向天文科研场景的一体化 AI 科研工具。系统以一个科研目标为入口，串联自动化数据分析、智能文献总结和天文学术图谱可视化，输出可复现、可溯源、可导出的科研数据与证据链。

## MVP 主案例

系外行星候选体与宿主恒星参数整合。

## 核心交付

| 交付 | 标准 |
| --- | --- |
| 公网 Demo | 主案例可稳定演示，支持缓存兜底 |
| 标准化数据集 | 字段、单位、来源、质量评分清楚 |
| 文献总结 | 结构化 JSON，结论绑定来源 |
| 学术图谱 | 节点和边可追溯到证据 |
| 导出物 | CSV、数据字典、溯源报告 |
| 材料素材 | 真实截图、接口样例、演示步骤 |

## 非目标

- 不做泛聊天助手。
- 不承诺任意科研问题全自动处理。
- 不承诺任意 PDF 或任意图表全自动解析。
- 不做大规模在线并发服务。
- 不用无来源模型输出替代科研证据。

## 决策原则

1. 主链路稳定优先于功能数量。
2. 科研可信优先于视觉包装。
3. 所有展示能力必须能被数据、接口或截图证明。
4. 文档口径不得超过系统实现。
