# Reference Materials

本目录只保存需要随提交包保留的外部赛题或规范材料，不是 production Authority。

## 长期材料

- [赛题要求.md](赛题要求.md)：外部赛题要求的仓库整理版。产品与工程解释由当前 Authority 体系负责。

## 边界

- 本目录不记录第三方实现项目、迁移清单、能力来源、比较矩阵或审查历史；
- 外部源码比较、capability gap、迁入决策与差异核对属于实施 Prompt / PR / Review 工作材料，不进入治理 Markdown；
- 产品与工程当前规则以 [Documentation Index](../README.md) 指向的 Authority 为准；
- 法律归因与许可证由法律文件负责；精确源码来源与 revision 由机器 provenance / lock metadata 负责；
- 外部材料不得成为 production implementation 的动态依赖。
