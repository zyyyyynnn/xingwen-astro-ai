## 这份资料解决什么问题

InnoSum-Bench 是学术摘要质量评估框架，从 Factual Consistency (FC) 和 Cognitive Coverage (CC) 两个维度评估 AI 生成的论文摘要质量。同时提供了论文结构化解析代码，可将 Markdown 格式论文自动拆分为 7 类章节并提取摘要。来自贵州大学，论文发表于 2026 年。

## 我们项目的哪个模块要用它

对应 `services/paper_pipeline`（D 岗位-梁津浩）。核心复用点：论文 Markdown 解析→章节自动分类→结构化摘要提取的完整流水线，以及论文摘要质量评估指标体系。

## 代码逻辑（paper_summary.py）

代码 550 行，使用 DeepSeek V3 作为 LLM，实现以下流水线：论文 Markdown 清洗 → 按标题拆分章节（`splite_paper_by_title`）→ LLM 章节自动分类（7 类）→ 各章节摘要提取 → 合并输出结构化 Markdown + JSON。

7 类章节分类：Research Background、Methodology、Experiment、Dataset、Discussion、Limitations、Research Questions。

关键函数：

- `splite_paper_by_title(text)`: 按标题拆分论文
- `classify_section(text)`: LLM 分类章节
- `extract_background` / `extract_methodology` / `extract_experiments_conclusion` / `extract_dataset` / `extract_discussion` / `extract_limitations` / `extract_questions`: 各类章节的摘要提取
- `summarize_paper(text)`: 主入口，编排全流程

## 评测框架

两个维度评估摘要质量：

FC (Factual Consistency)：8 个语义单元（核心问题、方法创新、核心技术、验证证据、性能结果、领域价值、研究局限、未来方向），每个 1-5 分，公式 `Score_FC = (1/8) Σ s_i`。

CC (Cognitive Coverage)：基于 Bloom 分类法 6 层级（记忆、理解、应用、分析、评价、创造），公式 `Score_CC = (1/N) Σ (0.7·S_j + 0.3·S_vj)`。

Mixture of Agents 评测流水线：DeepSeek-V3.1 提取语义单元 → Gemini 2.0 Flash / Qwen / GPT-4o-mini 独立评分 → 多数投票（≥半数通过），最多 5 轮迭代纠正。

## Qwen 迁移要点

代码中 LLM 调用层迁移到 Qwen：`base_url` 改为 `https://dashscope.aliyuncs.com/compatible-mode/v1`，`model` 改为 `qwen-plus` 或 `qwen-max`，`api_key` 改为 `os.getenv("DASHSCOPE_API_KEY")`。OpenAI 兼容模式，Prompt 模板和章节分类逻辑不用改。

## 我们可以借鉴什么

论文章节分类的 7 类体系可以直接复用到我们的 PaperSummary 结构。FC 的 8 个语义单元可以作为我们论文摘要的结构化字段定义。代码中的 Markdown 清洗和标题拆分逻辑可以直接用于 `services/paper_pipeline` 的论文解析模块。InnoSum 评测发现 LLM 摘要事实一致性较高但认知覆盖不足，SimPrompt 优于 CoT 在科学摘要场景的表现——这对我们设计论文解析 Prompt 有参考价值。
