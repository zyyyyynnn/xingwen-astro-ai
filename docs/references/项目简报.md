## Qwen API 接入

阿里云百炼平台，OpenAI 兼容模式。调用方式：`base_url=https://dashscope.aliyuncs.com/compatible-mode/v1`，`api_key` 通过环境变量 `DASHSCOPE_API_KEY` 注入。主力模型 qwen-plus（1.6 元/百万输入 token，6.4 元/百万输出 token）和 qwen-max（12 元/百万输入 token，36 元/百万输出 token）。每个模型各送 100 万 token 免费额度，有效期 90 天。模型调用与主算力由赛题方算力补贴覆盖，凭调用凭据走官方渠道核销。阿里云学生 300 元抵扣金已领取，可抵扣百炼 API 调用费用。

## 执行红线

前端不直连 Qwen、外部数据源或论文源。API Key 只放后端环境变量或部署平台 Secrets。模型输出必须结构化校验，不能直接当作事实。展示字段、文献结论、跨文献关系、图谱边必须能追溯到 Evidence。跨文献关系必须绑定 ReasoningTrace。seed list 只能作为兜底、评测基准或人工校验，不得冒充自动论文获取结果。缓存是元信息，不是主任务状态。未实现能力只能写为"规划""预留""后续扩展"，不得写成"已实现"。
